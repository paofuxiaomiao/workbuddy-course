# WorkBuddy 功能演示网页：交付资料包说明

> **资料包版本**：v1.0  
> **制作基线**：项目 Git `HEAD 8d5e7de`（v5.8 Tooltip 修复检查点）  
> **导出日期**：2026-08-22  
> **用途**：为项目移交、复盘、二次开发、离线审阅和素材溯源提供一份自包含的资料快照。

本资料包以“**不覆盖、不删改原始文件**”为前提建立。用户上传的截图、既有文档、聊天过程整理、当前项目源码、版本历史及实际构建验证记录均以副本形式保存。原始教师手册 PDF 与原始大尺寸 Logo 因项目检查点不接纳大媒体，已在用户授权后保留于项目外的完整原始归档；项目内则留下文本提取、校验值和恢复位置说明。有关具体文件来源、内容边界与引用关系，请参见 [04_References 原始文件清单](04_References原始文件清单.md)。

## 版本与使用建议

当前资料包对应的可验证代码快照是 Git 提交 `8d5e7de`。之后生成的“资料包目录”本身属于交付附加材料，并将在本次收尾检查点中被保存。若要运行网页，请进入 `source-code/` 所对应的项目根目录副本，安装依赖后执行 `pnpm run dev`；若只需审阅，请直接从本文件和四份编号 Markdown 文档开始。

| 使用目标 | 推荐入口 | 说明 |
|---|---|---|
| 设计复盘 | `02_设计思路与信息架构.md`、`05_迭代复盘图.md` | 查看设计决策、交互变化与关键提示词。 |
| 开发续作 | `03_项目结构地图.md`、`source-code/` | 先理解模块和数据流，再进入源码。 |
| 内容核查 | `source/original-inputs/`、`source/original-documents/` | 保留原始 PDF、截图和文字提取副本。 |
| 素材复用 | `01_提示词与素材清单.md`、`assets/` | 注意生图原始提示词仅有截断片段。 |
| 质量确认 | `source/test-records/build-and-typecheck.md` | 查看本次实际执行的类型检查与生产构建记录。 |

## 已知缺口与可替代方案

| 缺口 | 原因 | 可替代方案 |
|---|---|---|
| 完整原始生图提示词 | 历史记录仅保留截断前缀，完整请求未持久化 | 使用复现稿，并在下一次生成时保存完整参数；详见 [提示词原始记录](source/core-knowledge/prompt-provenance.md)。 |
| 生图服务 URL、模型版本、种子 | 本地未保存这些生成元数据 | 使用资料包中的轻量化 Logo 副本；原始 PNG 位于完整原始归档。 |
| 原始 PDF 与大尺寸 Logo 的项目内副本 | 项目检查点拒绝大于 1MB 的媒体文件 | 保留在项目外完整原始归档和原始媒体保险位置；项目内保留校验值、文本提取和恢复位置说明。 |
| 飞书原始 HTML / 全量离线导出 | 原页面采用动态虚拟滚动；本任务未保留页面原始 HTML | 使用 PDF 文本提取与已整理功能指南内容；线上链接记录在素材清单中。 |
| 原始逐字聊天日志 | 对话平台历史未提供可直接导出的逐字文件 | 使用 `source/core-knowledge/workbuddy-chat-process.md` 的可读版过程归档。 |
| 当前项目中的 GitHub 静态资源提交 | 早期历史中记录过图片推送，但当前本地基线回到 `8d5e7de`，该提交不在此快照中 | 资料包保留全部原始截图和 Logo；二次开发时可重新放入 `client/public/assets/`。 |
